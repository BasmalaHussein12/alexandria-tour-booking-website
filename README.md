# Alexandria Tour Booking Website

## Overview
This is a full-stack web application for booking tourist experiences in Alexandria.  
The system allows users to register, log in, browse tours, and save tour bookings to their account.

---

## Project Goal
The goal of this project is to simulate a real-world tourism booking platform by:
- Enabling user registration and authentication
- Allowing users to browse available tours
- Allowing users to book and save tours
- Managing user bookings through a database system

---

## Features
- User Registration (Sign Up)  
- User Login / Logout (Authentication System)  
- Browse available tours and packages  
- View detailed tour information  
- Save/book tours (Add to user account)  
- Store booking data in database  

---

## Technologies Used
- HTML  
- CSS  
- JavaScript  
- PHP  
- MySQL (Database)

---

## Authentication System
- Secure user registration with database storage  
- Login validation using PHP backend  
- Session management for user accounts  

---

## Booking System
Users can:
- Select a tour  
- Save/book the tour  
- Store booking information in the database  
- View their saved bookings (if implemented)  

---

## Database
The relational database manages:
- User accounts  
- Tour listings  
- User bookings (saved tours)  

SQL operations used:
- INSERT  
- SELECT  
- UPDATE  
- DELETE  

---

## Project Type
Full-stack web development project (PHP + MySQL)

---

## Outcome
A functional full-stack tour booking system with authentication, database integration, and a complete booking workflow including saving tours to user accounts.
